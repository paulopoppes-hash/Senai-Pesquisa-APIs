# Senai-Pesquisa-APIs

Pesquisa de 10 projetos que consomem APIs

## Descrição

Atividade consistente em pesquisar 10 projetos no GitHub que consumam APIs, clonar e analisar os projetos identificando o framework e a API utilizada, e gerar uma tabela em Markdown resumindo os projetos analisados.
